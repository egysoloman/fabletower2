## 持续迭代目标（长期节奏）

- **手感周（每周一次）**：快捷键覆盖更多界面、触屏手势、动画节奏微调
- **平衡数据驱动**：每次新增敌人/卡牌后跑一轮胜率扫描，异常立刻回滚
- **内容轮换**：每月 2-3 个新敌人/事件/遗物，保持 meta 新鲜（已完成 #1，下批 #2 待排）
- **质量门槛**：任何改动必须通过 103 引擎测试 + 4 服务端测试 + 前后端 typecheck + 生产构建；涉及 UI 的在浏览器实测
- **玩家反馈闭环**：每个迭代目标都来自真实对局体验（本条清单即由实际对局痛点驱动）
