# NEONSPIRE Balance Patch 2.0.0

- Game version: `0.1.1`
- Patch stack: `production-v4-mechanics`
- Stack version: `2.0.0`
- Base content: `content-2026.08.01`
- Resolved content fingerprint: `fnv1a32-07838e7a`
- Previous production stack: `production-v3-enemy-hp-95@1.0.0`

## Changes

Patch 2.0.0 retains every numeric change from Patch 1.0.0, including the 5%
enemy HP reduction, and promotes the independently retrained
`candidate-mechanics-relic-reinforced-one-shared4` mechanics finalist as one
versioned production layer: `character-mechanics-v4@4.0.0`.

### GHOST

- Stable is now the visible default state.
- Leaving Overdrive or Stealth returns GHOST to Stable.
- An Attack played in Stealth resolves first and then exits to Stable.
- Phase Locket still starts combat with **2 Stance Wall**.
- With Phase Locket equipped, every real stance transition grants 1 Energy.
- Re-entering the current state is not a transition and grants no Energy.
- Without Phase Locket, stance transitions grant no Energy.

### ARRAY

- A0 Max HP: 75 → 70. Ascension adjustments remain additive.
- ARRAY Attack cards command living summons instead of dealing direct body
  damage; their non-damage riders remain intact.
- Deploy Turret/Plating cost 1 and summon the Ferro/Bulwark role. Their
  upgrades summon the corresponding Prime role variant.
- Same-role summons share one board slot and stack to a maximum of 4 layers.
- Each layer adds one summon action, but all layers share one HP bar. Losing
  that shared body removes the whole role stack.
- A mixed formation adds at most +1 action power per layer, regardless of
  whether two or three roles are present.
- Drone Cradle does not pre-deploy a summon. It adds 1 HP to each summoned
  role's shared body; layers do not add further HP.
- These stacking rules apply only to ARRAY. Other characters keep independent
  one-layer summons.

## RL validation

The final evaluation used two independently retrained eight-policy
populations, with 2,048 evaluation episodes per character in each population.
Cross-population raw rates are supporting evidence; paired deltas within each
population remain the causal comparison.

| Character | Population A | Population B |
|---|---:|---:|
| RUNNER | 29.150% | 28.809% |
| VECTOR | 33.594% | 33.643% |
| GHOST | 33.740% | 34.424% |
| ARRAY | 35.205% | 31.787% |

ARRAY reached floor 16 in 74.902% / 73.145% of episodes. The retained two
Stance Wall layers kept GHOST aligned with VECTOR; removing them had previously
reduced GHOST to roughly 25.6% and was rejected.

## Runtime and rollback

The client and authoritative server still call `activateProductionBalance()`
at startup. The old stack remains built in and can be selected with
`activateBalanceStack('production-v3-enemy-hp-95')`; baseline content remains
available through `resetBalanceToBaseline()`.

Formal v4 and the RL finalist have a regression test that compares their
resolved ARRAY cards, starter relic hooks and mechanics tuning. Saves continue
to record the active stack id and deterministic content fingerprint.
