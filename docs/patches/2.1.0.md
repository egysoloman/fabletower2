# NEONSPIRE Balance Patch 2.1.0

- Game version: `0.1.1`
- Patch stack: `production-v4.1-array-fallback`
- Stack version: `2.1.0`
- Base content: `content-2026.08.01`
- Resolved content fingerprint: `fnv1a32-f070a46a`
- Previous production stack: `production-v4-mechanics@2.0.0`

## Changes

Patch 2.1.0 keeps every numeric and mechanical change from Patch 2.0.0 and
adds one independently removable layer: `array-fallback-pulse@1.0.0`.

### ARRAY fallback pulse

- Every single-target ARRAY Attack now deals **2** chassis damage before it
  commands living summons; its upgrade deals **3**.
- Every all-enemy ARRAY Attack now deals **1** chassis damage to each enemy
  before it commands living summons; its upgrade deals **2** to each enemy.
- Non-damage riders and summon commands are unchanged.
- With no living summon, an Attack therefore still makes small progress
  instead of becoming a zero-damage card.
- Summons remain the primary output. For example, an unupgraded Pulse Bolt
  deals 2 damage alone, 6 total damage with one Ferro Drone, and 10 total
  damage with two Ferro layers.

This patch does **not** increase summon HP, change the shared-body rule, add HP
per layer, raise the four-layer cap, restore the original ARRAY Attack damage,
or change ARRAY Max HP. Keeping those variables fixed prevents a survivability
and damage buff from landing at the same time.

## Validation

Deterministic engine tests cover empty-board single-target damage, one-Ferro
damage contribution, all-enemy targeting, upgraded values, patch composition,
and exact rollback to Patch 2.0.0. No local RL training or evaluation was run
for this hotfix.

## Runtime and rollback

The client and authoritative server continue to call
`activateProductionBalance()` at startup. Patch 2.0.0 remains built in and can
be restored with `activateBalanceStack('production-v4-mechanics')`; Patch 1.0.0
and baseline content remain available through their existing rollback paths.
