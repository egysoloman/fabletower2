# NEONSPIRE Balance Patch 1.0.0

- Game version: `0.1.1`
- Patch stack: `production-v3-enemy-hp-95`
- Stack version: `1.0.0`
- Base content: `content-2026.08.01`
- Resolved content fingerprint: `fnv1a32-8233820c`

## Changes

This is the first production balance patch. It promotes the RL finalist v3
character adjustments and reduces every enemy's base HP range by 5% (rounded
to whole HP).

### RUNNER

- Strike base damage: 6 → 8
- Defend base block: 5 → 7
- Cortex Link first-turn draw: 1 → 2

### VECTOR

- Vent base Heat conversion: ×2 → ×3

### GHOST

- Phase Blade base damage: 6 → 7
- Cloak Field base block: 5 → 6
- Phase Locket starting Stance Wall: 1 → 2

### ARRAY

- Deploy Turret: cost 1 → 2; base Turret 2 → 1
- Deploy Plating: cost 1 → 2; base Plating 2 → 1
- Drone Cradle no longer pre-deploys a Turret

## Runtime and rollback

The client and authoritative server call `activateProductionBalance()` during
startup. RL candidates go through `activateBalanceOverrides()`, which uses the
same resolver. `resetBalanceToBaseline()` restores the untouched content
catalog, and activating a stack repeatedly never compounds percentage changes.

Saved runs record the resolved patch stack id and content fingerprint for
telemetry and future migration work. Existing saves resume under the currently
deployed production rules.
